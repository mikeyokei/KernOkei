# Kerning Pair Checker

A web-based tool for type designers and typographers to check kerning pairs in fonts.

## Features
- Test any letter with the entire Latin alphabet and other character sets
- View letter pairs in first and second positions
- View letter triplets in first, middle, and last positions
- Upload and test custom fonts
- Toggle kerning on/off
- Different font size options
- OpenType stylistic set support
- Easy copying of results

## Usage
1. Enter a single letter in the input field
2. Click "Generate" or press Enter
3. View the kerning pairs and triplets
4. Toggle different character sets as needed
5. Upload a custom font to test
